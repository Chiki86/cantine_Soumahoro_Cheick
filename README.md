
Cantine - Calcul de commande

Auteur :Soumahoro Cheick Hamed Tidiane

Présentation

Ce programme JavaScript simule la gestion d'une commande dans une cantine scolaire.
Il détermine le prix unitaire du plat selon son code (1 à 3), calcule le montant
total avec une fonction `calculerTotal`, affiche un récapitulatif avec une boucle
`for`, puis calcule la monnaie à rendre ou le montant manquant.

 Exécution

    node cantine.js
